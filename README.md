# Devolução OS Contabilidade

App para o cliente montar o rascunho da NF-e de devolução ou de venda e enviar ao escritório pelo WhatsApp. Lê o XML ou a foto do DANFE (OCR no próprio aparelho, com Tesseract.js em `ocr/`, licença Apache 2.0).

Acesse: https://oscontabilidade.github.io/devolucao-os/
